# CANログファイル自動解析システム (Rust)

C言語での車載ECU開発（4年）の経験を活かし、メモリ安全かつ高速なRustを用いて開発したCANパケットのパース・車両状態監視システムです。

## 🛠️ システムの仕組みとデータ構造
外部の設定ファイル（JSON）から通信定義を動的に読み込み、一括で取り込んだログファイルを1行ずつ安全に解析します。

データの配列（パケット構造）は以下のルールでパースされます。
- **配列0 (先頭)**: 車速データ（設定ファイルのゲインを掛け算して km/h に変換）
- **配列1 (真ん中)**: ブレーキ状態（0x01 のビットマスクで ON/OFF を判定）
- **配列2 (一番右)**: シフトポジション（0x02ならニュートラル、0x03ならドライブなど match 構文で判定）

## 🚦 安全診断ロジック
パースされたリアルタイムな車両状態を監視し、以下の安全診断を行います。
1. **速度超過警報**: 100km/h を超えた場合に警告を出力。
2. **ブレーキ不整合警告**: N（ニュートラル）レンジにもかかわらずブレーキが踏まれていない危険状態を検知。

## 🔒 Rustによる安全設計（C言語との対比）
- C言語の `strtok` や `atof` で発生しがちな、データ破損時のヌルポインタアクセスやセグメンテーションフォルト（強制終了）を、Rustの `unwrap_or` 処理によって完全に排除しています。
- `match` 構文による型安全な条件分岐を採用し、仕様外の不正なデータ（未定義のシフトポジション等）が流れてきても、システムが暴走（未定義動作）を起こさず確実にキャッチする設計にしています。
